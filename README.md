# Logistics Management System

This repository contains the Delivery feature of the COMP 3500SEF group project. The Delivery demo runs locally with a React interface, a Spring Boot backend and sample data. The module documentation identifies the team integrations that still use Place holders.

| To do this | Start here |
|---|---|
| Build and run Delivery from source | [Delivery README](features/delivery/README.md) |
| Follow a demo | [Delivery walkthrough](features/delivery/docs/DEMO.md) |
| Connect another role or the shared database | [Integration guide](features/delivery/docs/INTEGRATION.md) and [API contract](features/delivery/API_CONTRACT.md) |
| Reproduce checks or inspect earlier evidence | [Testing guide](features/delivery/docs/TESTING.md) |
| Review the wider project requirements | [Project reference index](features/delivery/docs/project/README.md) |
| Inspect the repository build checks | [GitHub Actions workflow](.github/workflows/delivery-checks.yml) |

Build the app in `features/delivery` before launching it from this checkout. The repository-level GitHub Actions workflow builds and checks the Delivery source. The original developer ZIP contains the prebuilt app and the earlier project reference exports.
