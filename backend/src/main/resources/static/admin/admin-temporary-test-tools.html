Test tools Test mode

These tools exist only in test mode.

Stage 1

Create test user

Creates an active account with a temporary password.

End lock

Ends the 15-minute lock of an account, as if the time had run out.

Expire temporary password

Lets the temporary password of an account run out at once.

Set user status

Sets only the stored status of an account.

Stage 2

Create many test users

Creates 25 Client accounts, so that page numbers can be tested.

Create worker with active work

Creates a Warehouse Worker and a Delivery Worker who both have work in progress.
