Test tools Test mode

These tools exist only in test mode.

Stage 1

Create test user

Creates an active account with a temporary password.

How to use
Creates
An active account named after its role, for example test_warehouse_3, with a temporary password that is valid for 24 hours.
See it on
Users. The first login with this password asks for a new one.

End lock

Ends the 15-minute lock of an account, as if the time had run out.

How to use
Changes
The 15-minute lock of the account ends now, as if the time had run out.
Before
Lock the account with 5 wrong passwords on the login page.
See it on
Users: the account can log in again.

Expire temporary password

Lets the temporary password of an account run out at once.

How to use
Changes
The temporary password of the account runs out now.
Before
Give the account a temporary password with "Create test user" or "Reset password".
Not for
The super admin.
See it on
The login page: the password no longer works.

Set user status

Sets only the stored status of an account.

How to use
Changes
Only the stored status. Everything else about the account stays as it is.
Not for
The super admin.
See it on
Users, after a reload.

Stage 2

Create many test users

Creates 25 Client accounts, so that page numbers can be tested.

Create worker with active work

Creates a Warehouse Worker and a Delivery Worker who both have work in progress.

How to use
Creates
A Warehouse Worker with 2 orders being picked, and a Delivery Worker who holds 1 package and has claimed 1 pickup list.
Shows
Both usernames, their temporary passwords and the order references.
Next
Try "Change role", "Ban" or "Deactivate" on Users: each names the active work.

Stage 3

Create picking scan rows

Creates a sample order that is being picked, with six scan rows.

How to use
Creates
One order being picked, with 6 scan rows: 3 accepted, 1 reversed and 2 rejected.
Shows
The order reference.
See it on
Logs, tab Picking scans, with the reference as the order filter.

Create old log rows

Adds log rows just older and just newer than the keeping times.

How to use
Creates
Log rows just older and just newer than the keeping times. A second press replaces them.
Next
Press "Run log clean-up now": only the newer rows stay in Logs.

Run log clean-up now

Runs the daily clean-up of old log rows at once.

How to use
See it on
Logs: the card "Log clean-up" shows the run and the rows deleted.

Create private value log rows

Adds one audit row and one security row that hold private test values.

How to use
Creates
One audit row and one security row that hold private test values, such as a phone number.
See it on
Logs: the private values are hidden.

Stage 4

Set product stock

Sets the two stock numbers of a product, which Admin itself may not change.

How to use
Changes
The two stock numbers of the product, which Admin itself may not change.
See it on
Products, after a reload, with the flags "Low stock" and "Shortfall".

Stage 5

Create sample order set

Creates one sample order in each of the ten order statuses.

How to use
Creates
10 orders, one in each order status.
Shows
The 10 order references with their status.
See it on
Orders, and the order page of each reference.

Stage 6

Create shortage report

Reports a missing item of a sample order, as Warehouse would.

How to use
Creates
A shortage case, as Warehouse reports it. With the order reference empty, also a new sample order with 3 mugs and 1 pen.
Shows
The order reference and the case number.
See it on
Warehouse cases.
Example
Press it with the order reference empty, then again with the reference it showed: that order then has two cases.

Mark shortage resolved

Closes a waiting shortage case, as Warehouse would after restock.

How to use
Before
Decide "Wait for restock" for the case on Warehouse cases.
See it on
Warehouse cases, with the filter Resolved.

Create picking order

Creates a sample order that a Warehouse Worker is picking.

How to use
Creates
An order being picked, with 1 of 3 mugs picked.
Shows
The order reference and the worker.
See it on
Warehouse cases, card Picking tasks in progress.

Stage 7

Create failed delivery case

Creates a sample order whose delivery failed.

How to use
Creates
An order whose delivery failed, with that many failed attempts.
Shows
The order reference and the request number.
See it on
Delivery cases.
Example
1 failure, returned 8 days ago, no request: the flag "Final review".

Create held package

Creates a sample order whose package a Delivery Worker holds.

How to use
Creates
An order whose package a Delivery Worker holds.
Shows
The order reference, the package number and the worker.
See it on
Delivery cases, card Held packages.

Stage 8

Create refund case

Creates a cancelled sample order with one refund.

How to use
Creates
A cancelled order with an accepted payment and one refund in the chosen status.
Shows
The order reference, the refund number and the payment number.
See it on
Refunds.

Set provider answer

Sets the answer that the stand-in payment provider gives for one refund.

How to use
Changes
The answer that the stand-in payment provider gives for that refund.
Next
Press "Check provider status" in the row of that refund on Refunds.

Stage 9

Run privacy check

Searches every Admin answer for private data.

How to use
Shows
How many answers were checked, and each finding with its function and what was found.

Remove all test data

Empties every table except the accounts that are not test accounts.

How to use
Removes
Every row of every table and every test account. This cannot be undone.
Keeps
Your own account and every account that is not a test account.
