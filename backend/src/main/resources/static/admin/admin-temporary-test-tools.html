Test tools Test mode

These tools exist only in test mode.

Stage 1

Create test user

Creates an active account with a temporary password.

End lock

Ends the 15-minute lock of an account, as if the time had run out.

Expire temporary password

Lets the temporary password of an account run out at once.

Set user status

Sets only the stored status of an account.

Stage 2

Create many test users

Creates 25 Client accounts, so that page numbers can be tested.

Create worker with active work

Creates a Warehouse Worker and a Delivery Worker who both have work in progress.

Stage 3

Create picking scan rows

Creates a sample order that is being picked, with six scan rows.

Create old log rows

Adds log rows just older and just newer than the keeping times.

Run log clean-up now

Runs the daily clean-up of old log rows at once.

Create private value log rows

Adds one audit row and one security row that hold private test values.

Stage 4

Set product stock

Sets the two stock numbers of a product, which Admin itself may not change.
